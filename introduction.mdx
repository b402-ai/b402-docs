Open-source infrastructure for **agent payments** and **confidential DeFi**.
Live on Solana, Base, and BNB mainnet. Apache 2.0.

## Install for your agent

```bash
npx -y @b402ai/solana-mcp --install
```

One command writes b402 into Claude Code, Cursor, or Claude Desktop. Eleven
tools — `shield`, `unshield`, `private_swap`, `private_lend`, `private_redeem`,
`quote_swap`, `status`, `balance`, `holdings`, `watch_incoming`, `wallet_balance`.
Mainnet defaults. No RPC config required.

[MCP overview →](/solana/mcp/overview)

## Or use it from code

<CodeGroup>

```ts Solana
import { B402Solana } from '@b402ai/solana';
import { PublicKey, Keypair } from '@solana/web3.js';

const USDC = new PublicKey('EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v');
const SOL  = new PublicKey('So11111111111111111111111111111111111111112');

const b402 = new B402Solana({ cluster: 'mainnet', keypair });
await b402.ready();
await b402.shield({ mint: USDC, amount: 1_000_000n });
await b402.swap({ inMint: USDC, outMint: SOL, amount: 1_000_000n });
```

```ts EVM
import { B402 } from '@b402ai/sdk';

const b402 = new B402({ privateKey: process.env.PRIVATE_KEY });

// Gasless. Facilitator settles on chain.
await b402.shield({ token: 'USDC', amount: '100' });
await b402.swap({ from: 'USDC', to: 'WETH', amount: '10' });
```

</CodeGroup>

`npm install @b402ai/solana` · `npm install @b402ai/sdk`

[Solana quickstart →](/solana/quickstart) · [EVM quickstart →](/evm/quickstart)

## What's live

| Layer | Where |
|---|---|
| Solana shielded pool (Phase-9 dual-note) | mainnet |
| Solana Jupiter adapter (private swap) | mainnet |
| Solana Kamino adapter (per-user obligation) | mainnet |
| Solana percolator adapter (perp open / close) | devnet |
| Solana MCP server (`@b402ai/solana-mcp@0.0.28`) | npm + mainnet defaults |
| EVM Facilitator V3 (HTTP-402 / x402) | Base + BNB mainnet |
| EVM smart wallets (ERC-7579 Nexus) | Base + BNB mainnet |
| EVM privacy pool (Railgun fork) | Base mainnet |

Same b402 program IDs on Solana devnet and mainnet. EVM contract addresses
in each chain's reference.
